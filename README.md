# 같이보자 — 최대 4인 상영회

방장 1명이 화면과 소리를 공유하고, 친구 최대 3명이 브라우저에서 시청하며 채팅하는 웹사이트입니다.

## 맥에서 가장 쉽게 실행

1. Node.js LTS를 설치합니다: https://nodejs.org
2. 압축을 풀고 `start.command`를 더블클릭합니다.
3. 보안 경고가 뜨면 파일을 우클릭 → `열기`를 누릅니다.
4. 크롬에서 `http://localhost:3000`이 자동으로 열립니다.

직접 실행하려면 이 폴더에서:

```bash
npm install
npm start
```

## GitHub 웹 업로드

**`node_modules` 폴더는 절대 올리지 마세요.** 용량이 크고 파일이 수천 개입니다.

새 저장소의 `Add file` → `Upload files`에서 아래 항목만 올리면 됩니다.

- `public` 폴더
- `.gitignore`
- `package.json`
- `server.js`
- `render.yaml`
- `README.md`
- `start.command` (선택)

이 압축파일을 새로 풀었다면 전체 항목 수가 적어서 그대로 드래그해도 됩니다. 먼저 `npm install`을 했다면 생긴 `node_modules`만 제외하세요.

## 인터넷에 배포

1. GitHub 새 저장소에 위 파일들을 업로드합니다.
2. Render에서 GitHub 저장소를 연결해 Web Service 또는 Blueprint를 생성합니다.
3. 배포된 HTTPS 주소로 접속합니다.
4. 방을 만들고 초대 링크를 친구들에게 보냅니다.

## 화면과 소리 공유

- 데스크톱 Chrome 권장
- `화면 공유 시작` → 영상이 재생되는 **Chrome 탭** 선택
- **탭 오디오 공유**를 반드시 켜기
- Mac에서 VLC/IINA 등 외부 앱 소리는 바로 전달되지 않을 수 있음
- DRM(복제 방지)이 적용된 서비스는 검은 화면이 나올 수 있음

## 참고

WebRTC P2P 방식이라 방장이 시청자 최대 3명에게 각각 영상을 보냅니다. 끊기면 공유 화질을 720p로 낮추세요. 일부 공용·회사·학교 네트워크에서는 직접 연결이 막힐 수 있습니다.

## 모바일 시네마 UI
- 영상이 화면 전체를 차지하는 넷플릭스 스타일
- 최근 채팅이 영상 왼쪽 아래에 반투명 오버레이로 표시
