# 같이보자 v7 — iOS/Android 모바일 OTT UI

친구들과 화면을 공유하고 반투명 채팅으로 함께 보는 WebRTC 상영회입니다.

## 모바일 동작

- Android Chrome: 브라우저에서도 `집중 모드`로 전체화면 진입 가능하며, 홈 화면 설치도 지원합니다.
- iPhone/iPad Safari: Safari 정책상 채팅이 포함된 임의 요소 전체화면이 제한되므로, `홈 화면에 추가` 후 앱 아이콘으로 실행하면 주소창과 탭바 없이 같은 플레이어 UI를 사용합니다.
- 두 운영체제 모두 영상 원본은 잘리지 않는 `contain` 방식이며, 빈 공간에는 흐린 영상 배경을 표시합니다.
- 가로/세로 회전 및 모바일 키보드가 열릴 때 `visualViewport` 크기에 맞춰 플레이어 높이를 다시 계산합니다.

## 배포

압축 안의 파일 전체를 기존 GitHub 저장소에 덮어쓰고 커밋합니다. Render 자동 배포가 완료된 뒤 기존 설치 앱은 삭제하고 홈 화면에 다시 추가하면 캐시 혼선을 줄일 수 있습니다.
